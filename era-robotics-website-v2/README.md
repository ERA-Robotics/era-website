# ERA Robotics Website V2

This is the upgraded Next.js version based on the current ERA Robotics Framer visual direction.

## Included

- Homepage
- Solutions
- Industries
- Products
- Case Studies
- Resources
- About
- Contact
- Responsive desktop, tablet and mobile layouts
- SEO metadata
- Dark enterprise visual system
- Physical AI, edge computing and integration positioning

## Upload to GitHub

1. Download and unzip this package.
2. Open the empty GitHub repository `ERA-Robotics/era-website`.
3. Click the blue **uploading an existing file** link.
4. Drag all unzipped files and folders into GitHub.
5. Commit as `Initial ERA Robotics website v2`.

## Deploy to Vercel

1. Open Vercel.
2. Click **Add New → Project**.
3. Import `ERA-Robotics/era-website`.
4. Keep the detected framework as Next.js.
5. Click Deploy.

## Important before public launch

- Replace the CSS placeholder logo with the official ERA logo asset.
- Add approved photography/video.
- Confirm permission before publishing customer names or logos.
- Replace generic case-study wording with verified facts and metrics.
- Connect the contact form to HubSpot, Formspree, Resend or another production form service.
- Add Privacy Policy and Terms pages.
